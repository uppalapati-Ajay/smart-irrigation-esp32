    System architecture · blue = telemetry, amber = commands
    How the firmware thinks · one loop, five jobs
    1Sample

    Reads the soil sensor 10 times, averages the readings and maps the raw ADC value to 0-100 %.

    2Decide

    Hysteresis control: pump ON below the low threshold, OFF above the high one. A 10 s run limit and 5 s cooldown protect the plant.

    3Act

    Drives GPIO26, which switches a relay and pump on real hardware (an LED in the simulation).

    4Report

    Publishes a JSON message every 2 seconds with moisture, temperature, humidity, pump state and settings.

    5Listen

    Receives commands to switch mode, run the pump or change thresholds, so the dashboard is a real remote control.
