ESP32 · MQTT · Wokwi

What if the soil
could talk?

An ESP32 reads soil moisture, decides when to water using hysteresis control, and streams everything over MQTT to a live dashboard — where you can switch the pump on from anywhere.

▶ Open live dashboard (demo) Try the control logic ★ View on GitHub

How it works

Sense, decide, route, report. Telemetry flows up to the dashboard; commands flow back down to the ESP32.

📡

Live every 2 s

Moisture, temperature, humidity and pump state as one JSON message.

🧮

10-sample average

The ADC is read ten times per cycle so one noisy sample can't trigger the pump.

🎯

Hysteresis band

Starts below 30 %, stops above 45 %, holds state in between — no flicker.

🛡️

Safety cut-off

10 s maximum run and a 5 s cool-down protect the pump in every mode.

Build it in five minutes

No hardware needed — paste the firmware into a new Wokwi ESP32 project and press ▶.

1️⃣

Simulate

Open Wokwi, paste firmware/smart_irrigation_v2.ino and wokwi/diagram.json, add the libraries.

2️⃣

Watch

Open the dashboard. Turn the potentiometer — the gauge and pump follow.

3️⃣

Control

Switch to manual and run the pump from anywhere, then back to auto.

Send a command from any MQTT client

mosquitto_pub -h broker.hivemq.com -t smartirrigation/ajay4821/cmd -m "pump:on"
mosquitto_sub -h broker.hivemq.com -t smartirrigation/ajay4821/data
CommandEffect
mode:autoHysteresis control on
mode:manualAuto-control off
pump:on / pump:offSwitch to manual and run / stop the pump

⚠️ Public broker. The default setup uses the public HiveMQ broker with no authentication — anyone who knows the topic can read the data and send pump commands. Change ajay4821 to a unique id before sharing, and use a private broker with TLS for real hardware.
